# 纵向比较：实现约束与验收

本模块用于研究数据比较，不构成疾病变化、风险或治疗结论。

## 检查配对

- 按数据库 `subject_id` 校验同一受试者，不根据显示名称匹配。
- 两次检查必须 `ready`。接受有效的完整 `YYYYMMDD` 或 `YYYY-MM-DD` 检查日期。
- 既往日期必须严格早于当前日期。无日期、无效日期、同日或逆序检查均不可运行；导入时间不参与判断。
- 候选的指标清单使用每个指标的最新记录；旧的 computed 值不会覆盖新记录的 not_computed 状态。

## 几何与配准

- 使用预览记录的 `spacing`、`origin`、`direction` 建立 SimpleITK LPS 毫米坐标。不会假设 RAS 或以场景中心坐标替代物理坐标。
- 检查尺寸、文件字节数、有限正间距、有效原点和正交方向。已有 affine 必须与 `direction × spacing` 和 origin 一致。
- 固定图像为既往检查，移动图像为当前检查。返回的 4×4 变换 `prior_to_current` 将既往物理点映射到当前物理点，包含旋转中心偏移。
- `not_run` 表示缺少预览；加载或计算异常为 `failed`；优化未收敛、覆盖不足为 `low_quality`；工程检查通过为 `completed / research_qc_passed`。
- 质控检查有限互信息、有效采样点、真实停止原因和双向视野覆盖率（最低 0.5）。优化器名称中的 Gradient 不再被误认为收敛。
- 视野覆盖和优化收敛不等于解剖准确性。互信息不是准确率；该阈值没有临床验证。

## 测量可比性与 API

- 每项测量追溯自身 `provenance.segmentation_id`，核查分割归属、状态、模型、关联体数据及流水线，不使用最新分割替代实际来源。
- `measurement_grid=native_label` 时使用该测量 `native_geometry.spacing`。预览间距变化不会直接使相同原始网格测量不可比。
- 方法、来源、单位、验证状态、AHA 段、标签、测量网格、模型或流水线不一致时抑制差值。缺失测量和非有限数值同样抑制差值。
- 心腔容积 `LV/RV/LA/RA_VOLUME` 必须具有明确且一致的 `provenance.cardiac_phase`。系统不会从单时相检查猜测时相。
- 配准未通过时抑制所有纵向差值。该规则偏保守，包括原本不依赖空间对应的整体指标。
- 保留两侧原始数值和 `currentUnit / priorUnit`。`delta / percent` 为 null 表示不可比；基线为零时百分比为 null。
- `comparability` 是包含 `comparable`、`warnings` 和两侧来源信息的对象。前端直接显示该对象的结论及原因。
- 读取历史结果时不输出 NaN/Infinity；没有当前配准质控的旧结果不再展示可比差值。
- 配准失败仍保存 Comparison 和审计事件，HTTP 200 返回 `status=failed` 的结果对象。请求配对错误为 400，未找到记录为 404，格式错误为 422。
- 前端显示结果整体状态，运行中锁定既往选择，并通过请求版本号丢弃过期响应。

## 主 agent 集成注意事项

1. UI 成功场景准备同一受试者、不同且有效检查日期的 ready 记录。两次当日 demo 导入不能自动构成既往比较。
2. 心腔容积无采集时相时显示不可比是预期行为；不要为通过验收而推断真实检查时相。合成测试可以明确标注其设计时相。
3. 旧预览如 affine 与物理几何冲突需重新处理；本模块不改写历史数据。未发现的旧几何来源错误仍无法仅凭数值一致性排除。
4. 仍仅做预览体刚性配准，无变形配准、人工解剖标志复核或临床验证。
