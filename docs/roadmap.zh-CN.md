## 当前实现 — 2026-10-20

本次整合保留 `aa8a648` 的研究能力，并合入 API 稳定代码与报告语言记录。“已实现”表示软件路径存在且有本地契约/已知答案验证，不代表临床验证或真实模型服务已可用。

## M1 — 数据与几何维护

保留已运行的 DICOM/合成路径及原始标签 NIfTI 路径。患者元数据为 LPS，RAS 数组排列和 RAS 参考图谱是不同概念。保留裁剪后原点、包含 spacing 的 affine、标签最近邻对齐、原始 mask 全分量和中心化预览单位。DICOM 模型测量仍沿用其分割网格，不将公开 NIfTI 的原生定量泛化为所有输入路径。

## 图谱与归一化

19 器官/109 靶点目录、细部按需加载和参考靶点模拟均已实现，心脏图谱到患者的研究配准也已实现。保留语义映射与无效/退化输入拒绝逻辑。下一步是外部精度/质控评价及新增已获许可的解剖数据，而不是把既有能力重新列为未实现。参考射线模拟仍限教学，患者靶向操作不在当前已验证范围内。

## M2 — 模型与报告验收

- TotalSegmentator 保持显式选择和任务许可前提。保留官方输出名映射、NIfTI 物理几何、必要 mask 检查、独立输出目录及安装包版本追溯。真实权重推理未验证，包版本不代表已核验的权重。
- AI 接口和 mock SDK 测试已实现。须另行接入获授权的真实 key 并评价提供商响应，才能声称真实调用已完成。
- 保留证据 ID、数字核查、显式模板回退和人工复核；模型/服务不可用时不能生成虚假结论。
- 保留报告修订及批准的 `baseVersion`/`baseContentHash` 检查。生成时记录 `lang=en|zh`，草稿保存该语言，读取不改变。单份报告工作流内的历史保留不等于流水线重跑后的永久留存。
- PDF 导出、更完整的模型治理与临床部署仍需单独验收。

## M2.5 — 公开数据外部验证

公开 NIfTI 图像/标签导入和评价链路已实现。报告数据集精度或临床性能之前，应完成来源/许可核验及独立 ImageCAS/ASOCA 评价，记录 Dice/HD95 与适当的中心线/管腔参照。mock 输出与合成 mask 不能替代真实推理或外部验证队列。

## M3 — 纵向对比

对比流程已实现。要求同一受试者、ready 检查、有效且严格有序的采集日期、通过研究配准质控，以及兼容的测量来源/时相/单位。缺失日期、配准失败或不可比测量均抑制差值。当前使用预览体刚性配准；形变配准及外部临床精度仍属后续工作。该功能是对比，不是疾病进展判断或个体事件预测。

## M4 — 冠脉 AI 验证

保留骨架覆盖失败时停止分析的检查，以及范围明确的最长路径管径摘要。在提出狭窄结论之前，需接入并验证真实管腔模型、分析失败模式，并与 QCA/IVUS 比较。FFR-CT 需要独立验证的压力求解器或模型。

## M5 — 生产与临床准备

仍需完成认证角色/OIDC、审计导出、保留策略、备份/灾备、部署监控、数据库/对象存储和任务扩展、安全评价、临床安全复核及监管规划。本地测试和带医生标签的批准事件不能替代这些要求。
