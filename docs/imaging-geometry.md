# 原始标签、物理坐标与显示预览

本轮将公开 NIfTI 的测量网格与显示网格分开。它解决软件层面的数据丢失和坐标错误，
不代表模型已通过真实病例或临床验证。没有标签时，公开导入仍不能自动生成冠脉分割。

## 处理约定

- 原始影像与标签分别保存，上传文件同名也不会覆盖。记录两个文件的 SHA-256；
  数据集名称仍是上传者声明，未据此声称数据来源已经验证。
- 原始标签保留为 UInt16，支持 1–65535 编号。负数、非整数、越界和空标签拒绝处理。
  不根据编号 1 推测解剖语义；只有显式命名的冠脉标签进入冠脉分析。
- NIfTI 的 origin、spacing、direction 以 SimpleITK 返回的 **LPS 物理坐标**解释。
  RAS 是显示数组轴排列；重排不改变同一体素对应的物理位置。
- 预览用线性插值处理 CT、最近邻处理标签，保留完整视野。预览看不到细小结构时会记录
  警告；原始体积、原始标签表面仍保留该结构。
- 标签网格必须位于影像视野内，否则导入失败。允许物理空间一致的轴翻转和裁剪标签，
  不按数组尺寸猜测对齐。
- `affine` 定义为 `voxel_index_xyz → LPS_mm`，包含间距和裁剪偏移。
  定义依据 [SimpleITK 物理图像与重采样说明](https://simpleitk.readthedocs.io/en/master/fundamentalConcepts.html)。

## 测量与三维

公开标签体积、冠脉骨架和管径均在**原始标签网格**计算，不使用显示预览。测量 provenance
记录 `measurement_grid=native_label`、原始几何和输入哈希。修改预览分辨率不应改变测量。
现有 DICOM 模型测量仍沿用其分割网格，不能据此声称所有输入的原生定量已经完成。

公开标签 GLB 保留所有连通分量，在边界补背景后提取表面，不自动平滑。大网格仍可能
简化，仅用于显示；体积使用体素计数。不同冠脉标签合并成一棵研究标签树分析，避免
多个分支重复写入相同全树指标。总骨架长度包括全部连通分量；显示中心线及管径统计
只覆盖最长路径，不能解释为完整分支评估或临床 QCA。

每个原始连通分量必须对应一个连通的骨架。若细化导致任何分量消失或断裂，
中心线分析失败并返回 `not_computed`；不会把其余分量的结果当作完整分析。
原始网格与标签体积仍可查看。分支数采用合并相邻分叉节点后的最大非分叉路径数：
两条独立直线为 2，独立闭环为 1，孤立点为 0。

患者场景坐标使用：

```text
center_mm = (preview_dims_xyz - 1) * preview_spacing_xyz / 2
scene = (preview_index_xyz * preview_spacing_xyz - center_mm) * scale
scale = 3 / max(preview_dims_xyz * preview_spacing_xyz)
```

因此标签体素中心、GLB、参考靶点和冠脉中心线采用同一中心化约定。原生标签点先通过
LPS 物理空间映射到预览索引轴毫米，再应用该公式。旧衍生文件不自动迁移，需重新处理。

MPR 根据方向矩阵显示放射学方向，十字线、点击和标记共用映射。斜切图像明确标注
“原生斜切”并显示复合方向；它不是患者正交重切。演示模式保留原界面行为。

## 验证

```sh
npm run test:frontend
cd server
.venv/bin/python -m pytest tests/test_imaging_geometry.py tests/test_public_import.py tests/test_registration.py
```

测试使用已知几何的合成输入：非零原点、非等距体素、轴排列/翻转、超过 255 的标签、
微小结构、分离血管、边缘结构、同名上传、未知语义和错误几何。前端测试覆盖全部
48 种带符号轴排列。另以浏览器检验导入、MPR、逐结构显示和报告流程。

这些是实现验收。真实模型推理、公开病例的外部精度、医生复核和临床用途验证仍需
分别完成，不能由测试通过替代。
